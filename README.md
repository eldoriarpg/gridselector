# Grid Selector

Grid Selector is an add-on for [Schematic Brush Reborn](https://github.com/eldoriarpg/SchematicBrushReborn).
Players build on a grid of plots, click the plots they want, and the builds on those plots become the schematics of
their brush. PlotSquared worlds can be used instead of grid clusters.

Everything else is in the [documentation](https://docs.eldoria.de/schematic-brush-reborn/grid-selector).

## Requirements

| What | Version |
|---|---|
| Server | Paper 1.21.11 or newer |
| Java | 25 |
| Other plugins | Schematic Brush Reborn 3, FastAsyncWorldEdit |
